# monaarchives

A friendly user web api application design to archive user's Manga, Manhwa, Manhua, LN, and Webnovel to favorite source/websites provider. So instead of having multiple website to scanner, official provider, or pirated website. My API will create user account and user can create & manage their own archives of illustration stories to their favorite website instead of having to remember multiple site or create multiple accounts to different services.
